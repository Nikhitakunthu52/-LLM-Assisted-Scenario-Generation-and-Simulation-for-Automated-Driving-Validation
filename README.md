# -LLM-Assisted-Scenario-Generation-and-Simulation-for-Automated-Driving-Validation
Develop an AI and LLM assisted framework capable of automatically generating OpenSCENARIO driving scenarios from natural language prompts, videos, or vehicle recordings, and executing them in high fidelity simulation environments such as esmini, CARLA, CarMaker.
